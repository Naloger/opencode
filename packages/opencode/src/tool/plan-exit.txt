Ask the user if they want to switch from plan agent to build agent to start implementing the completed plan.

---

## Usage notes

- Call this tool after completing the planning phase
- Asks the user for confirmation to switch to build agent
- Only switches if user confirms "Yes"

---

## Failure modes

| Error | Cause | Fix |
|---|---|---|
| User declines | User chooses "No" to stay in plan mode | Continue planning or ask for clarification |

---

## Rules

- Only call after writing a complete plan to the plan file
- Ensure all questions have been clarified with the user
- Be confident the plan is ready for implementation before calling
