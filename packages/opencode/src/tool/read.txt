Read a file or directory from the local filesystem. If the path does not exist, an error is returned.

---

## Required

- `filePath` — The absolute path to the file or directory to read

---

## Optional args

- `offset` — The line number to start reading from (1-indexed). Defaults to 1
- `limit` — The maximum number of lines to read. Defaults to 2000

---

## Usage notes

- Contents are returned with each line prefixed by its line number as `<line>: <content>`
- For directories, entries are returned one per line (without line numbers) with a trailing `/` for subdirectories
- Any line longer than 2000 characters is truncated
- To read later sections of large files, call this tool again with a larger offset
- Can read image files and PDFs and return them as file attachments
- Use the grep tool to find specific content in large files

---

## Failure modes

| Error | Cause | Fix |
|---|---|---|
| File not found | Path does not exist | Verify the filePath parameter or use glob tool to find correct path |
| Permission denied | Insufficient permissions | Check file permissions |
| File too large | File exceeds size limits | Use offset/limit to read in chunks or use grep for specific content |

---

## Rules

- Always use absolute paths
- Call this tool in parallel when reading multiple files
- Avoid tiny repeated slices (30 line chunks); read larger windows when possible
- Use glob tool if unsure of the correct file path
