Ask the user questions during execution to gather preferences, clarify requirements, or get decisions on implementation choices.

---

## Required

- `questions` — Array of question objects, each containing:
  - `question` — The question text to ask
  - `options` — Array of possible answer options (optional)
  - `multiple` — Whether multiple answers can be selected (default: false)

---

## Usage notes

- Use when you need user input during execution
- Questions can have predefined options or allow custom answers
- When custom is enabled, a "Type your own answer" option is added automatically
- Answers are returned as arrays of selected labels

---

## Failure modes

| Error | Cause | Fix |
|---|---|---|
| No questions provided | Empty questions array | Provide at least one question |
| Invalid question format | Question object missing required fields | Ensure each question has a question field |

---

## Rules

- Ask questions when instructions are ambiguous
- Use multiple: true for questions allowing multiple selections
- Put recommended options first with "(Recommended)" label
- Don't include "Other" options when custom is enabled
