Performs exact string replacements in files.

Use this tool with a strict payload.

Required args:
- arg: `filePath`
  - absolute file path only
  - example: `C:\\repo\\app\\src\\main.ts`
- arg: `oldString`
  - exact text currently in file
  - include exact spaces/tabs/newlines
  - example: `const port = 3000\n`
- arg: `newString`
  - replacement text (must be different from `oldString`)
  - example: `const port = 3001\n`

Optional args:
- arg: `replaceAll`
  - `true` = replace every match
  - `false` (default) = require exactly one match
  - example: `true`

Example payload:
```json
{
  "filePath": "C:\\repo\\app\\src\\main.ts",
  "oldString": "const port = 3000\n",
  "newString": "const port = 3001\n",
  "replaceAll": false
}
```

Rules:
- You must use your `Read` tool at least once in the conversation before editing.
- When copying from Read output, never include the `lineNumber: ` prefix.
- ALWAYS prefer editing existing files in the codebase. NEVER write new files unless explicitly required.
- Only use emojis if the user explicitly requests it.

Failure modes:
- If `oldString` is not found exactly: `oldString not found in content`.
- If `oldString` matches multiple places and `replaceAll` is false: `Found multiple matches for oldString...`.
- If multiple matches happen, either:
  - provide more surrounding context in `oldString`, or
  - set `replaceAll` to `true` when replacing all occurrences is intended.
