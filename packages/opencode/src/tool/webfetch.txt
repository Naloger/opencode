Fetches content from a specified URL and converts it to the requested format. Supports HTML to Markdown conversion and text extraction.

---

## Required

- `url` — The URL to fetch content from (must start with http:// or https://)

---

## Optional args

- `format` — The format to return content in: "text", "markdown" (default), or "html"
- `timeout` — Optional timeout in seconds (max 120)

---

## Usage notes

- Automatically converts HTML to Markdown when format is "markdown"
- Extracts plain text from HTML when format is "text"
- Returns images as file attachments
- Handles Cloudflare bot detection by retrying with different User-Agent
- Limited to 5MB response size

---

## Failure modes

| Error | Cause | Fix |
|---|---|---|
| Invalid URL | URL doesn't start with http:// or https:// | Provide a valid HTTP/HTTPS URL |
| Request failed | Server returned error status | Check if URL is accessible |
| Response too large | Content exceeds 5MB limit | Use a different tool or find smaller content |
| Timeout | Request took too long | Increase timeout or try later |

---

## Rules

- Prefer specialized web tools if available for specific tasks
- Use HTTPS URLs when possible
- Choose appropriate format based on content type needed
- Handle large responses by using text format for extraction
