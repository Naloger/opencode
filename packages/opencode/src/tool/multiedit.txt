Perform multiple sequential edits to a single file in one operation. Applies a series of find-and-replace operations in order.

---

## Required

- `filePath` — The absolute path to the file to modify
- `edits` — Array of edit operations, each containing:
  - `filePath` — The absolute path to the file to modify
  - `oldString` — The text to replace (must match exactly)
  - `newString` — The replacement text (must be different from oldString)

---

## Optional args

- `replaceAll` — Replace all occurrences of oldString (default: false) - per edit operation

---

## Usage notes

- All edits are applied sequentially in the order provided
- Each edit operates on the result of the previous edit
- All edits must succeed or none are applied (atomic operation)
- Ideal for making multiple changes to different parts of the same file

---

## Failure modes

| Error | Cause | Fix |
|---|---|---|
| oldString not found | Text doesn't match file contents exactly | Re-read file and copy oldString precisely |
| Same old/new string | oldString and newString are identical | Ensure they are different |
| Sequential conflicts | Earlier edits change text needed by later edits | Reorder edits or adjust oldString values |

---

## Rules

- Always read the file first to understand its contents
- Ensure all edits result in valid, correct code
- Use absolute file paths
- Plan edits to avoid conflicts between sequential operations
- Only use emojis if explicitly requested by user
- Use replaceAll when renaming variables or strings across the file
