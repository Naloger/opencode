Search the web using Exa AI for real-time information and content scraping. Provides up-to-date results beyond knowledge cutoff dates.

---

## Required

- `query` — Web search query string

---

## Optional args

- `numResults` — Number of search results to return (default: 8)
- `livecrawl` — Live crawl mode: "fallback" (use as backup) or "preferred" (prioritize live crawling). Default: "fallback"
- `type` — Search type: "auto" (balanced), "fast" (quick results), or "deep" (comprehensive). Default: "auto"
- `contextMaxCharacters` — Maximum characters for context (default: 10000)

---

## Usage notes

- Returns content from the most relevant websites
- Supports domain filtering and advanced search options
- Automatically handles current year context (current year: {{year}})
- Use for accessing information beyond knowledge cutoff

---

## Failure modes

| Error | Cause | Fix |
|---|---|---|
| No results found | Query didn't return matches | Try different search terms |
| Search error | API returned error | Check query format or try again later |
| Timeout | Request took too long | Try a simpler query |

---

## Rules

- Always include current year ({{year}}) when searching for recent information
- Use appropriate search type based on needed depth vs speed
- Prefer live crawling for time-sensitive information
- Use contextMaxCharacters to control response length
