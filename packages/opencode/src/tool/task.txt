Launch a new agent to handle complex, multistep tasks autonomously. Creates a subagent session that can perform tasks with specialized capabilities.

---

## Required

- `description` — A short (3-5 words) description of the task
- `prompt` — The task for the agent to perform
- `subagent_type` — The type of specialized agent to use for this task

---

## Optional args

- `task_id` — Resume a previous task by providing its task_id. Continues the same subagent session instead of creating a fresh one
- `command` — The command that triggered this task

---

## Usage notes

- Launch multiple agents concurrently when possible for better performance
- Each agent invocation starts with fresh context unless task_id is provided to resume
- The agent's outputs should generally be trusted
- Clearly specify whether the agent should write code or just do research
- Include verification steps in the prompt when possible (e.g., test commands)

---

## When to use

- When instructed to execute custom slash commands
- For complex multistep tasks that require specialized agents
- When proactively using agents that should be called automatically

---

## When NOT to use

- For reading specific files - use Read or Glob instead
- For searching specific classes - use Glob instead
- For searching within 2-3 specific files - use Read instead
- For simple tasks that can be done with existing tools

---

## Failure modes

| Error | Cause | Fix |
|---|---|---|
| Unknown agent type | subagent_type doesn't exist | Check available agent types in the description |
| Permission denied | Agent not allowed for this context | Choose a different agent type |

---

## Rules

- Provide highly detailed task descriptions for agents to work autonomously
- Specify exactly what information the agent should return
- Use task_id to resume previous sessions when continuing work
- Trust agent outputs but verify critical results
