Writes content to a file on the local filesystem. Overwrites existing files and creates new ones as needed.

---

## Required

- `content` — The content to write to the file
- `filePath` — The absolute path to the file to write

---

## Usage notes

- Will overwrite existing files if one exists at the provided path
- Automatically formats the file after writing
- Shows LSP diagnostics if there are errors in the written file
- Use this tool when you need to create new files or completely replace existing ones

---

## Failure modes

| Error | Cause | Fix |
|---|---|---|
| File not read first | Attempting to overwrite existing file without reading it first | Use Read tool first to see current content |
| Permission denied | Insufficient permissions | Check file permissions |
| Path invalid | Directory doesn't exist | Create parent directories first if needed |

---

## Rules

- ALWAYS prefer editing existing files with the Edit tool instead of overwriting
- For existing files, you MUST use the Read tool first to see current contents
- NEVER proactively create documentation files (*.md) or README files unless explicitly requested
- Only use emojis if the user explicitly requests it
- Use absolute paths for filePath
